공정·출하 검증 대시보드 — 회사 PC 실행 방법
================================================

1. 준비물
   - Node.js 20 이상 설치 (https://nodejs.org 에서 LTS 버전 다운로드 후 설치)
     설치 확인: 명령 프롬프트(cmd)나 PowerShell에서 `node -v` 입력 → v20.x.x 이상이면 OK
   - 이 폴더 전체(zip 압축 해제한 것) — 인터넷 연결 필요(최초 1회, 패키지 설치 시에만)

2. 설치 (최초 1회만)
   - 이 zip을 원하는 위치에 압축 해제
   - `process-dashboard` 폴더로 이동
   - 그 폴더에서 명령 프롬프트를 열고 아래 명령 실행:
       npm install
     (인터넷에서 필요한 패키지를 내려받음, 1~2분 정도 소요)

3. 실행
   - 같은 폴더(`process-dashboard`)에서:
       npm run dev
   - "Local: http://localhost:3000" 같은 문구가 뜨면 준비 완료
   - 웹 브라우저를 열고 http://localhost:3000 접속

4. 테스트
   - 화면 상단 "파일 선택"으로 가상데이터 Excel 5종(zip에 같이 들어있음: Kuk_가상데이터_*.xlsx)을
     한꺼번에 선택해서 업로드
   - 상단 탭(Upload Center / Yield·NG Analysis / Process Dashboard / Shipment Risk /
     Shipment Draft / Shipment Progress)을 눌러가며 화면 확인
   - 실제 회사 데이터로 테스트하려면, 같은 형식(헤더 구조)의 Excel 파일로 바꿔서 업로드하면 됨
     (파일명은 상관없음 — 헤더/구조로 자동 판별)

5. 종료
   - 명령 프롬프트 창에서 Ctrl+C

참고
   - 브라우저에서 업로드한 내용은 그 PC/브라우저의 localStorage에만 저장됨(서버로 전송 안 됨).
     다른 PC나 다른 브라우저에서는 새로고침해도 안 남아있고, 다시 업로드해야 함.
   - 진행 상황·설계 배경은 PLAN.md 참고.
